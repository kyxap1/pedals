# Alesis SR18: copy changes

## Sources

- `sr18_reference_manual_reve.pdf` (Reference Manual Rev E, doc 7-51-0250-E): https://www.alesis.com/rscdn/919/documents/sr18_reference_manual_reve.pdf. The copy the user supplied is byte-identical to this file.
- `sr18_quickstart_guide_revc.pdf` (Quickstart Rev C, doc 7-51-0249-C): https://www.alesis.com/rscdn/919/documents/sr18_quickstart_guide_revc.pdf. Only the English pages are used.
- `sr18_patternsoundlist.pdf` (Sound, Pattern, Kit List V1.00): https://www.alesis.com/rscdn/919/documents/sr18_patternsoundlist.pdf
- All three are listed on https://community.alesis.com/products/view/sr18. The product page https://www.alesis.com/products/view/sr18 redirects to alesisdrums.com, which lists no documents.

## Conventions

- Button names the manual prints in brackets or caps (`[PLAY]`, PLAY) are set as `<kbd>` keycaps. The quickstart's button icons in its tutorial step column become the same keycaps.
- The manual's Wingdings bullets become square list bullets.
